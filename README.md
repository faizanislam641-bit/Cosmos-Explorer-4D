# 🌌 Cosmos Explorer 4D — Hyperreal Space Simulator

Ultra-high-fidelity 3D space simulation with black hole experiment lab.

## ✨ Features

- 🌞 Realistic Sun with GLSL plasma shader
- 🪐 12 Planets with procedural textures
- ⚫ Ultra-realistic Black Hole with gravitational lensing
- 🧑‍🚀 **Real 3D models** for experiments (astronaut, rocket, asteroid, probe, planet, star)
- 🎥 **5 camera views** for experiments: Chase, BH, Top, Side, First-Person
- ⏱️ **Sim speed control** + Slow-Mo mode
- 📊 **Fall tracker** with distance, speed, ETA
- 🌊 **Impact flash** + Horizon overlay

## 🎮 How to Use

1. Click any **experiment card** in the right sidebar
2. Object spawns near the black hole
3. Camera auto-follows in **Chase View**
4. Switch views with the **Experiment Camera** panel (left side)
5. Adjust **SIM SPEED** for slow-motion
6. Watch the **Fall Tracker** to see distance + ETA to event horizon

## 🎥 Camera Views

- **🎥 Chase Cam** — behind the falling object
- **⚫ Black Hole Cam** — near the event horizon
- **⬆ Top Down** — bird's eye view
- **➡ Side View** — perpendicular to fall
- **👁 First Person** — from inside the object
